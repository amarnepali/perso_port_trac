1. first intalled postgres in docker using command 
    docker pull postgres   // pull the latest 17.5  checked command "docker exec-it postgresql bash" "psql --version"
    docker run -itd -e POSTGRES_USER=amar -e POSTGRES_PASSWORD=amar -p 5432:5432 -v ./data:/var/lib/postgresql/data --name postgresql postgres

    check in docker : psql -h localhost -p 5432 -U amar
